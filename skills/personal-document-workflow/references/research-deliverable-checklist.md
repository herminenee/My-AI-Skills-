# Research Deliverable Quality Checklist

Use this checklist for laboratory data, scientific figures, research presentations, and reports.

## Input and provenance
- [ ] Input file and version identified
- [ ] Data origin / measurement date known or explicitly unavailable
- [ ] Units and experimental conditions preserved
- [ ] Missing values, duplicates, and exclusions documented
- [ ] No private data included unnecessarily

## Analysis
- [ ] Calculations/formulas are reproducible
- [ ] Sample size, uncertainty, and relevant assumptions stated
- [ ] Numerical values checked against source
- [ ] Derived quantities distinguished from observations
- [ ] No conclusions beyond evidence

## Communication
- [ ] Audience and central message clear
- [ ] Figures include axis labels, units, legends where needed
- [ ] Tables have meaningful headers, consistent rounding and units
- [ ] Summary includes outcome, interpretation, caveat, next action
- [ ] Previous visual identity preserved when requested

## Delivery
- [ ] File format matches request
- [ ] File opens without errors
- [ ] Layout checked for clipping, overlapping elements, or missing fonts
- [ ] Links, chart labels, table alignment, and pagination verified
- [ ] Output file, verification performed, and unresolved limitations reported
