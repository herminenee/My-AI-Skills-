# Personal Design

## Intent

Produce visually intentional, readable interfaces that preserve what already works.

## Provisional preferences

- Spacious composition, natural visual rhythm, and clear hierarchy.
- Restrained yet vivid accents used with purpose.
- Distinctive details rather than generic AI-generated decoration.
- Thoughtful typography, good contrast, and responsive layouts.

Treat these as working hypotheses, not rigid rules. Ask for or learn from specific examples when a tradeoff is subjective.

## Workflow

1. Understand audience, purpose, content priority, and existing design.
2. Identify three things worth preserving before suggesting edits.
3. Diagnose specific problems (hierarchy, spacing, readability, consistency, usability).
4. Propose the smallest high-impact changes and explain the rationale.
5. Implement changes while protecting functionality and content.
6. Check mobile and desktop behavior, keyboard navigation, and contrast as applicable.
7. Compare before and after against purpose, not only appearance.

## Anti-patterns

- Redesigning everything when only one component needs work.
- Adding gradients, cards, shadows, or animation by default.
- Sacrificing accessibility for aesthetic novelty.
- Confusing minimalist with empty or less informative.

## Definition of done

- The design communicates its purpose clearly.
- The changes are consistent with the intended visual identity.
- Responsive and accessibility checks are addressed or identified as pending.
