# Design references (editable)

## Current working principles

1. **Openness:** Give content room to breathe; avoid cramped interfaces.
2. **Light and warmth:** Prefer purposeful illumination and visual clarity, not obligatory pastel palettes.
3. **Hierarchy:** Make the most important idea obvious.
4. **Natural composition:** Let relationships among elements guide layout.
5. **Restraint:** Every decorative element should justify its presence.
6. **Continuity:** Preserve features the user already chose and values.
