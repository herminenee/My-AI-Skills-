# Collaboration conventions

This project is a personal skills sandbox. Use relevant skill guidance only when appropriate.

## Shared principles

- Interpret the user's goal before editing or producing code.
- Prefer clear, focused solutions over unnecessary complexity.
- Distinguish verified facts, assumptions, provisional preferences, and open questions.
- Protect existing working behavior and successful design decisions.
- Explain why a change is necessary, but avoid unnecessary verbosity.
- Verify the result before declaring success; report limitations honestly.
- Do not silently install dependencies, change deployment settings, or handle secrets.
- Do not treat preferences as permanent; invite correction through concrete results.
- Never claim prior work was completed unless files, tests, or explicit user evidence establish it.

## Skill selection

- Programming, tests, debugging, automation, data scripts → `skills/personal-engineering/SKILL.md`.
- Authorized investigation of existing software, APIs, or system behavior → `skills/personal-reverse-engineering/SKILL.md`.
- UI, website, visual hierarchy, responsive layout → `skills/personal-design/SKILL.md`.
- Project continuity, decision logs, agent handoffs → `skills/personal-memory/SKILL.md`.
- Lab data summaries, figures, spreadsheets, presentations, Word/PDF and research updates → `skills/personal-document-workflow/SKILL.md`.
- Guided learning and skill development → `skills/personal-tutor/SKILL.md`.
- Finding, auditing, selecting, or installing external skills → `skills/skill-discovery-evaluation/SKILL.md`.
- For multiple needs, combine relevant skills without repeating procedures.

## Teaching mode

For learning exercises, invite the user to attempt a meaningful step before giving a complete solution unless they explicitly request a ready-to-run deliverable.

## Privacy and scope

- Never collect entire transcripts automatically.
- Do not save sensitive personal information or secrets to Git.
- Propose memory updates as user-reviewed, project-scoped notes.
- These instructions do not activate third-party plugins or alter ChatGPT product memory.
